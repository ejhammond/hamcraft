Download HamCraft

  1. 01

    Download the pack

    Use the download button. Keep the .mrpack file somewhere easy to find—you’ll import it in step 3.

  2. 02

    Install Modrinth

    Get the Modrinth App, then sign in with the Microsoft account that owns Minecraft Java.

  3. 03

    Import the pack

    In Modrinth, click the + / Add button and choose From file. You can also drag the .mrpack onto the app window. Modrinth creates a Minecraft 26.2 + Fabric instance and downloads everything automatically.

  4. 04

    Press Play

    Launch the new instance. If Modrinth complains about Java, point it at a Java 25 install, such as Adoptium Temurin 25.

  5. 05

    Add the server

    In Minecraft, go to Multiplayer → Add Server. The address will be shared on Discord.

HamCraft

HamCraft is a private Minecraft server with minimal modding. Our philosophy on mods is that they should smooth out rough edges rather than change the core gameplay.

Highlights

Less-punishing death

Dying drops a grave instead of scattering your items. You have 2 hours to get back to it.

Potion stacking

Potions of the same type stack, so they're finally worth carrying. Empty shulker boxes stack too.

Respectful explosions

Creeper, Ghast, and Wither explosions still hurt, but they won't destroy blocks. TNT and fire are still destructive!

No insomnia

Phantoms won't spawn due to lack of sleep. Instead, they spawn every night — but only above Y=160.

Tree chopping

Hold V with an enchanted axe to fell an entire tree in one go. Takes as long as chopping by hand — just fewer clicks.
